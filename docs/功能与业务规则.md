# 功能与业务规则

本文只描述产品功能与业务规则：用户能做什么、关键判定、边界与空态/异常怎么处理。实现细节见 [系统架构与设计](系统架构与设计.md)。

## 产品定位

SonicTrack 音乐可视化（整合版）是一个 Windows 桌面程序：浅色「组件库」主界面里可以选择可视化组件，在独立窗口中打开；多个组件可以同时运行。声音来自本机当前默认播放设备的输出（系统正在播放的声音）。

当前内置三类组件：

- **3D 频谱瀑布（V6.1）**：按频率显示响度，柱体形成向左移动的瀑布效果。
- **桌面声波（V10）**：按时间显示波形，可在桌面上以悬浮窗形式显示。
- **复古功放表（V0.0.1）**：以三组圆形模拟表分别显示低音、中音 / 人声和高音电平。

## 主界面与组件库

- 主界面以卡片展示可用组件，并提供分类导航：**全部组件**、**频谱**、**声波**、**已打开**、**设置**、**关于**；解锁后还可出现 **开发者选项**。
- 可用搜索框按名称、说明等关键词筛选；无匹配时提示「没有匹配的组件」。
- 「已打开」仅列出正在运行的组件（设置窗口已打开，或桌面悬浮窗仍在运行）；当前没有运行中的组件时提示「还没有打开的组件」。
- 每张卡片可：
  - **打开设置**：打开该组件的独立设置窗口（若已因悬浮窗而隐藏，则重新显示并前置）。
  - **打开悬浮窗**：不先打开设置窗口，直接启动该组件的桌面悬浮窗（组件须支持悬浮窗）。
  - **关闭悬浮窗**：关闭该组件正在运行的桌面悬浮窗。
- 卡片会反映运行状态文案，例如设置窗口已开、悬浮窗运行中、或两者兼有。
- 多个组件可以同时运行。

## 窗口与生命周期

以下规则以当前程序行为为准（设置窗口与桌面悬浮窗可独立存活）。

### 组件设置窗口与桌面悬浮窗

对支持桌面悬浮窗的组件（当前：3D 频谱瀑布、桌面声波、复古功放表）：

- 关闭**设置窗口**时，若桌面悬浮窗仍开着：设置窗口只是**隐藏**，捕获与绘制继续；卡片显示悬浮窗相关状态；可通过「打开设置」再次打开设置窗口。
- 关闭**桌面悬浮窗**后：若设置窗口此前已隐藏，则该组件会彻底结束（隐藏的设置窗口随之真正关闭）。
- 可从主界面卡片**只开悬浮窗、不开设置窗口**。
- 设置窗口与悬浮窗都可通过卡片或托盘侧操作关闭悬浮窗；强制退出应用时会一并关掉设置窗口与悬浮窗。

### 主界面与托盘

- 点击主界面**右上角关闭**时的行为，由「设置 → 主界面关闭」决定（默认：**界面隐藏进托盘**）：
  - **界面隐藏进托盘**：主界面隐藏到任务栏通知区域（托盘）；各组件的设置窗口按上面的规则处理（有悬浮窗则隐藏设置并保留悬浮窗）。**即使当前没有任何桌面悬浮窗**，选择此项时也不会因关主界面而退出。首次进入托盘时会提示仍在运行、单击图标可回主界面。
  - **直接退出软件**：结束仍打开的组件窗口（含悬浮窗）并完全退出程序。
- 软件**启动时即显示托盘图标**，主界面可见时托盘也保持显示。
- 托盘图标**单击**用于关闭 / 恢复悬浮窗：首次单击记住当前已开的组件种类并关闭全部悬浮窗；再次单击恢复这组悬浮窗。双击图标或菜单「显示主界面」→ 恢复主界面并置于前台；**不关闭、不隐藏**托盘图标。
- 托盘右键菜单包括：「显示主界面」、按当前运行中的悬浮窗列出的「关闭『某组件』悬浮窗」（多个时可「关闭全部悬浮窗」）、「退出」。
- 自动悬浮窗管理覆盖所有支持的悬浮窗，只管理已经由用户打开的组件，不会启动未运行的组件。静音自动隐藏的悬浮窗会在声音恢复时重新显示；托盘单击隐藏的悬浮窗不会因当前声音仍在播放而立刻弹回，会等到声音先静音、再恢复，或由用户再次单击托盘恢复。
- 主界面已隐藏到托盘期间，关掉最后一个（或全部）桌面悬浮窗时，程序**不会**因此自动退出；可通过托盘「显示主界面」回来，或「退出」结束程序。
- 托盘选择「退出」→ 结束全部组件（含悬浮窗）并退出程序（与设置中关闭行为无关）。

## 组件：3D 频谱瀑布（V6.1）

### 用户能做什么

- 在设置窗口中查看实时预览：频谱柱体向左平移，高度与颜色随响度保留记录感；可按住左键平移预览画面（不改变相机参数）。
- 调节分析与显示相关参数（业务名称，界面上以滑条/文案呈现），主要包括：
  - **柱高压缩**：高柱压得更多、低柱更少；颜色不变；为 0 时相当于原来的分贝柱高。
  - **回看位置**：0 为实时；增大可查看更早的历史（可回看范围由历史长度决定，不改变柱底座尺寸）。
  - **内部黑柱不透明度**：仅影响桌面悬浮窗里彩柱之间的黑柱；外围仍完全透明。
  - **历史长度**（列数）、**频率分辨**、**增益系数**、**采样率**（列/秒）、**对比度**。
  - **新柱稳定**（毫秒）：只稳定新输入的响度，历史柱不反复变形；为 0 表示关闭。
  - **视角**：水平、俯仰、距离、左右、上下；**重置视角**恢复到上次保存的视角与预览位置（未保存过的项用默认）。
  - **高频 / 低频**范围（界面以 kHz / Hz 标注）。
- **保存参数**：保存当前滑条参数与悬浮窗相关选项，下次启动自动恢复。
- **打开桌面悬浮窗**：桌面上只显示彩色柱子；拖动柱子可移动窗口；右键可关闭。可选 **悬浮窗置顶**、**鼠标穿透**（开启后点击会落到后方窗口，需在主设置窗口关闭悬浮窗或取消穿透）。
- 声音来源：本机当前默认播放设备的输出。

### 边界与持久化

- 参数与窗口相关状态会写入程序目录下的组件参数/窗口配置文件；损坏或缺失时按程序默认处理（不要求用户手工编辑文件）。
- 预览与悬浮窗可同时存在；具体显示以当前界面开关为准。

## 组件：桌面声波（V10）

### 用户能做什么

- 在设置窗口中查看预览声波；参数即时生效，并与悬浮窗位置等一并自动保存。
- 主要可调项（业务名）：
  - **增益**、**时长**、**线宽**、**抗锯齿**。
  - **目标更新频率**（如 60 / 120 / 144 / 240）。
  - **信号来源**：本机播放音频、演示波形、复杂压力波形。
  - **主声波颜色**：珊瑚、青蓝、白色、深灰。
  - **显示底层声波**及其颜色；底层相对主声波有轻微偏移，主声波保持不透明。
  - **悬浮窗置顶**、**鼠标穿透**、**保护底板**（自动选择对比色）。
  - **显示预览**（关闭可减少双窗口负载）；关闭预览后可提示「预览已暂停，桌面悬浮窗继续更新」。
  - **预览背景**：深色，或与主声波同色。
- **打开桌面悬浮窗**：拖动调整位置；右键关闭。启用鼠标穿透后，需用设置窗口上的按钮关闭悬浮窗。
- **重新连接音频**：在音频源异常或切换后可手动重连。
- 声音来源：本机当前默认播放设备的输出（选择「本机播放音频」时）。

### 边界与持久化

- 参数与悬浮窗位置等自动保存到程序目录下的组件参数文件；非法或越界值会在加载时被限制到合法范围或回退默认。
- 可选演示/压力波形，用于无真实音频时的展示与压力场景。

## 组件：复古功放表（V0.0.1）

### 用户能做什么

- 在设置窗口中查看三组圆形复古表盘：**低音（20–250 Hz）**、**中音 / 人声（250 Hz–2 kHz）**、**高音（2–20 kHz）**；不显示总电平表。
- 每个表盘同时显示实时指针和峰值指针。峰值快速跟随上升，保持约 650 ms 后以约 8 dB/s 缓慢回落；实时针快速响应并平滑移动。
- 调整 **输入增益**（0.1×–10×）、悬浮指针阴影（0–100%）、悬浮仪表大小（120–400 px）和组间距（0–80 px）。
- 使用 **显示标尺数字** 开关，同时控制设置窗口与悬浮层上的分贝数字；刻度弧线和刻度线保持显示。
- 打开透明置顶悬浮窗并拖动定位。悬浮层**只绘制指针、标尺弧线、刻度线和数字**；不悬浮表盘底色、标题、设置控件或其他装饰。
- 使用「重新连接音频」恢复默认播放设备捕获；捕获失败时在设置窗口显示原因。
- 声音来源：本机当前默认播放设备输出（WASAPI loopback）。分析使用 4,096 点 Hann 窗 FFT；中音和高音表分别有 +3 dB / +6 dB 的**表显校准**，用于改善指针活跃度，不表示扬声器的分频标准。

### 边界与持久化

- 增益、阴影、悬浮尺寸、组间距及悬浮窗位置自动保存到程序目录的 `vu-meter-parameters.json`；缺失或损坏时使用默认值。
- 首次集成启动时，如果新参数文件不存在，会读取独立版 `%LOCALAPPDATA%\SonicTrack\VintageAmpMeters\settings.json` 中可识别的参数；之后只写整合版参数文件，不修改独立组件配置。
- 设置窗口关闭而悬浮窗仍运行时，设置窗隐藏，音频捕获与指针更新继续；关闭悬浮窗后，已隐藏的设置窗会彻底关闭。


## 设置

侧栏「更多」下的 **设置** 页包含主界面关闭行为，以及桌面悬浮窗自动管理。

### 主界面关闭

- **界面隐藏进托盘**（默认）：点击主界面右上角关闭 → 隐藏进托盘，程序继续运行。
- **直接退出软件**：点击主界面右上角关闭 → 退出程序。
- 托盘菜单「退出」始终退出，不受此项影响。
- 该选项保存在程序目录的应用设置文件中；旧文件无此字段时按「隐藏进托盘」处理。

### 悬浮窗管理

用于设置已打开悬浮窗的静音自动隐藏行为与声音来源（按应用）。

### 用户能做什么

- **悬浮窗无声时自动隐藏**：开启后对所有支持的悬浮窗生效，但仅管理已经由用户打开的组件；不会启动未运行的组件。所选声音来源持续无声约 2.5 秒后自动隐藏已开悬浮窗；声音恢复时重新显示先前因静音自动隐藏的悬浮窗。
- **声音来源（应用）**：
  - **监听全部**：系统默认播放设备上，任一非系统声音的应用会话有声音时，视为「有声音」。
  - **仅监听勾选的应用**：只把列表中勾选的应用算作静音判定来源；可同时勾选多个。列表展示当前可识别的播放应用（进程），并显示有声音 / 静音或空闲；已勾选但当前未播放的应用仍会保留在列表中以便取消勾选。
  - 可随时 **刷新列表**。

### 能力边界（重要）

- **可视化画面**仍来自本机**默认播放设备的混合输出**（与改前相同），不会把某一应用的声音单独拆出来只画这一路。
- 「声音来源」里的应用勾选，**只用于**判断悬浮窗是否应保持显示，**不改变**频谱/波形实际听到的混音内容。
- 若系统或权限导致枚举不到会话，列表可能为空；此时「监听全部」在无会话时视为无声音；「仅监听勾选」在未勾选任何应用时视为无声音。

### 持久化

- 自动隐藏开关、监听模式和勾选应用保存在程序目录的应用设置文件（与开发者选项同一文件）中；自动隐藏默认覆盖所有支持的悬浮窗，不提供逐组件筛选；有效声音峰值阈值见「开发者选项」。

### 与手动操作的关系

- 用户仍可用卡片、设置窗口、托盘手动打开或关闭悬浮窗；用户主动关闭会结束该悬浮窗的自动管理会话。
- 自动管理仅隐藏已由用户打开且持续无声约 2.5 秒的悬浮窗；声音恢复时只重新显示此前因静音自动隐藏的悬浮窗，不会启动未运行的组件。托盘单击属于临时隐藏：保留关闭前的组件快照，声音仍在播放时不立即弹回；声音经历静音后再恢复时可自动重新显示。

## 开发者选项

- **解锁**：在「关于」页，连续点击大标题「关于」5 次，且每次间隔不超过约 1.5 秒。侧栏「更多」下方会出现「开发者选项」。
- 若已开启，再次按同一手势会提示已开启，不会重复开关。
- **可调内容**（对三个组件窗口里的银灰珊瑚滑条实时生效）：
  - 滑轨宽度（约 8–36 px，默认 8）
  - 圆点大小（约 24–64 px，默认 24）
  - 滑轨阴影强度（约 0–200%，默认 10%；100% 接近原组件阴影观感，0 为无阴影）
  - **有效声音峰值阈值**（约 0–100%，默认 **15%**）：用于静音自动隐藏的会话峰值判定；持续低于则视为无有效声音。设为 0% 时回退到极低可测底噪阈值。
- **恢复默认**：一键恢复滑杆外观三项默认值（不影响有效声音峰值阈值）。
- **持久化**：开发者选项、滑条尺寸与声音阈值保存在程序目录的应用设置文件中；删除该文件即恢复默认值。

## 空态 / 异常 / 边界

| 场景 | 行为 |
|------|------|
| 某分类/搜索无结果 | 提示「没有匹配的组件」 |
| 「已打开」且无运行中组件 | 提示「还没有打开的组件」 |
| 无法创建组件窗口 | 弹窗说明无法打开该组件及原因 |
| 无法打开桌面悬浮窗 | 弹窗警告；可提示去设置窗口查看原因 |
| 未处理的运行时错误 | 弹窗显示错误信息；同时尝试写入程序目录下的崩溃日志，程序尽量不直接崩溃退出 |
| 读不到桌面壁纸 | 主界面背景退回纯浅灰（不影响组件功能） |
| 参数文件缺失/损坏 | 使用内置默认；不要求用户修复文件格式 |
| 鼠标穿透开启 | 用户无法再靠点击悬浮窗本身关闭时，须用设置窗口或主界面/托盘的关闭悬浮窗操作 |

## 维护约定

凡改动触及**用户可见功能**、**判定规则**、**窗口/托盘/悬浮窗生命周期**、**可调参数含义或范围**、**空态/异常文案或处理方式**，必须同步更新本文档。实现落点与目录说明更新 [系统架构与设计](系统架构与设计.md)；文档索引见 [docs 说明](README.md)。
