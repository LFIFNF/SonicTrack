## 技术栈（一句话）

Windows 桌面 WPF 应用（.NET 8，`net8.0-windows`），音频捕获用 NAudio；可视化组件在独立窗口中运行，可带桌面悬浮窗。

## 模块分层

```
App 启动 (App.xaml / App.xaml.cs)
 └─ Shell（启动器、托盘、卡片、开发者滑条外观、壁纸背景）
      ├─ 打开 Components/V61（SonicTrack.V61）设置窗 / 悬浮窗
      ├─ 打开 Components/V10（SonicTrack.WaveCore）设置窗 / 悬浮窗
      └─ 打开 Components/VintageAmpMeters（SonicTrack.VintageAmpMeters）设置窗 / 悬浮窗
Theme/Theme.xaml —— 全局浅色样式与画刷
Assets/ —— 图标等静态资源
```

- **Shell**：组件库主界面；不实现频谱/波形渲染。
- **Components/V61、V10、VintageAmpMeters**：各自负责分析或绘制、预览、桌面悬浮窗与参数读写，并通过 `IOverlayComponent` 接入壳层生命周期。
- **Theme / Assets**：主题与资源。

## 主数据流

音频（可视化画面）：默认播放设备 loopback（NAudio）→ 组件内解码 / 频谱或波形缓冲 → 预览与/或桌面悬浮窗绘制。

悬浮窗无声自动隐藏：`AudioSessionMonitor` → `OverlayAutoController` → `IOverlayComponent.CloseOverlay` / 打开回调。覆盖所有支持悬浮窗的组件，但仅管理由用户打开的组件；静音关闭后声音恢复时重新显示此前自动隐藏的悬浮窗，不启动未运行组件。托盘临时隐藏保留用户意图，并等待静音到有声的转换；应用勾选只驱动静音判定，画面仍是默认设备混音。

复古功放表：WASAPI loopback → `AudioMeterAnalyzer` FFT / 三段电平 → 同步渲染主表与悬浮层；设置窗与悬浮层共享分析器，并通过 `IOverlayComponent` 独立存活。

主界面关闭（1.0.2）：若 `AppPreferences.CloseHidesToTray`（默认 true）则 `HideToTray`（可无悬浮窗）；否则完整退出。托盘「退出」始终退出。托盘下关光悬浮窗不再自动退出（`CheckTrayOnly` 为空操作）。

## 构建 / 运行 / 验证

```powershell
dotnet build -c Release
dotnet run -c Release --project SonicTrack.App.csproj
```

建议手工验证（改生命周期或托盘时）：

1. 设置选「界面隐藏进托盘」（默认）：只开悬浮窗 → 关主界面 → 应进托盘，悬浮窗仍在。
2. 托盘下关掉最后一扇悬浮窗且主界面仍隐藏 → **不应**自动退出；托盘「显示主界面」可回来，「退出」才结束。
3. 悬浮窗运行中关设置窗 → 设置窗隐藏、悬浮窗仍在；再「打开设置」应恢复。
4. 设置选「界面隐藏进托盘」、无悬浮窗时关主界面 → 应进托盘（不退出）。
5. 设置选「直接退出软件」→ 关主界面应退出（有无悬浮窗均同）。
