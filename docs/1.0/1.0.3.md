# 1.0.3 更新日志

**日期：** 2026-10-16（Asia/Shanghai）

## 变更要点

### 有效声音峰值阈值（悬浮窗自动管理）

- 自动开/关悬浮窗时，以音频会话**峰值电平**判定是否有**有效声音**（不再仅凭会话“活跃”状态）。
- 峰值**持续低于**可配置比例 → 视为无声 → 按既有静音延迟关闭已托管悬浮窗。
- 峰值**达到或超过**该比例 → 按既有逻辑自动打开。
- 用于过滤听歌识曲等极低电平、却长期占用会话的情况。
- **开发者选项**新增「有效声音峰值阈值」滑杆：**0–100%**，默认 **10%**；为 0% 时回退到极低可测底噪阈值。
- 偏好字段 `EffectiveSoundPeakPercent` 写入 `app-settings.json`。

### 托盘

- **启动时即显示**托盘图标（不必先点关闭进托盘）。
- 通过托盘单击/双击或「显示主界面」恢复主窗口时，**不关闭、不隐藏**托盘图标。
