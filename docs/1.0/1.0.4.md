# 1.0.4 更新日志

**日期：** 2026-10-16（Asia/Shanghai）

## 变更要点

将截图确认的参数整理为**出厂默认值**（新安装、参数文件缺失/损坏，以及开发者选项「恢复默认」对应项会回到这些值）。已有本地参数文件中的用户设定不受影响，除非删除对应文件或手动恢复。

### V6.1 3D 频谱瀑布

- 柱高压缩 **1.28**
- 内部黑柱不透明度 **80%**
- 增益 **7.33**；对比度 **1.11**
- 视角：水平 **0°**、俯仰 **85°**、距离 **6**、左右 **-3.2**、上下 **0.1**
- 悬浮窗置顶 **开**、鼠标穿透 **关**

### V10 桌面声波

- 抗锯齿 **关**；目标刷新 **240**；信号源本机播放
- 增益 **3.0**；显示时长 **50 ms**；线宽 **1.0 px**
- 悬浮窗 **320×80**
- 主色珊瑚；底层声波 **开**、颜色深灰
- 置顶 **开**、穿透 **关**、保护底板 **关**
- 显示预览 **关**；预览背景深色

### 开发者选项

- 滑轨宽 **8 px**、圆点 **24 px**、滑轨阴影 **10%**（「恢复默认」同步）
- 有效声音峰值阈值默认 **15%**

未列出的其它参数保持原有默认。
