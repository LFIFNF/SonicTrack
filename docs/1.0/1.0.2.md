# 1.0.2 更新日志

**日期：** 2026-10-16（Asia/Shanghai）

## 变更要点

- **取消**自动退出规则：
  - 无桌面悬浮窗时关闭主界面不再强制退出（由下方「关闭行为」决定）。
  - 主界面已隐藏到托盘期间，关掉最后一个桌面悬浮窗时，程序**不再**自动退出。
- **设置**新增「主界面关闭」：
  - **界面隐藏进托盘**（默认）：点击右上角关闭 → 主界面隐藏进托盘，程序继续运行。
  - **直接退出软件**：点击右上角关闭 → 结束全部组件并退出。
- 托盘菜单「退出」仍会真正退出程序。
- 偏好字段 `CloseHidesToTray` 写入 `app-settings.json`（默认 `true`；旧配置文件无此字段时按默认隐藏进托盘）。
