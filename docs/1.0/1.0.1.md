# 1.0.1 更新日志

**日期：** 2026-10-16（Asia/Shanghai）

## 变更要点

- 侧栏「更多」新增 **设置** 入口。
- **悬浮窗管理**：
  - 可启用自动打开 / 关闭桌面悬浮窗。
  - 可选择自动管理「3D 频谱瀑布」「桌面声波」。
  - **声音来源**按系统正在播放的应用：支持「监听全部」或勾选多个指定应用；列表可刷新。
  - 有声音时打开所选悬浮窗；持续无声音约 2.5 秒后自动关闭。
- 偏好写入 `app-settings.json`（与现有开发者选项共存，不破坏旧字段）。

## 能力边界

- 可视化仍捕获**默认播放设备混合输出**；应用勾选仅驱动自动开/关，不拆分单应用音轨。
