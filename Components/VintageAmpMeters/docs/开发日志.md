# VintageAmpMeters 开发日志

## v0.0.1 — 2026-10-22

- 建立独立 .NET 8 / WPF 技术验证组件，使用 NAudio WASAPI loopback 采集系统默认播放设备。
- 初始版本新增四个从左至右排列的复古模拟表盘：总电平、低音、中音 / 人声和高音。
- 实现 4,096 点 Hann 窗 FFT，以总频谱功率和分频段功率计算仪表电平。
- 每个仪表均显示实时指针和峰值指针；峰值快速跟随上升，保持 650 ms 后以 8 dB/s 缓慢回落。
- 提供 0.1×–10× 即时增益滑块，保存至用户本地配置文件并在下次启动时恢复。
- 增加重新连接音频入口、采集错误状态提示及非法增益回退。
- 将表盘重绘为圆形金属边框与暖色背光效果，并修正无音频输入时的电平基线，使实时针和峰值针都从 -24 dB 起始。
- 将指针更新从 30 ms 定时器切换为屏幕渲染同步回调；加入实时针快速起音、平滑回落，并预计算 FFT 窗函数。
- 修复峰值针不回落：保持截止时间改用单调时钟的绝对秒数，避免截止时间永不到达。
- 将表盘内容标题上移并下移标尺弧线，避免 VU、频段标题与刻度标签重叠。
- 移除总电平表，按低音 20–250 Hz、中音 250 Hz–2 kHz、高音 2–20 kHz 重分频；中音和高音表分别采用 +3 dB / +6 dB 指示校准，提高高音表响应。
- 移除仪表固定宽高，改为随三列布局等比例缩放，并降低窗口最小尺寸。
- 新增可开关的透明置顶悬浮窗，悬浮层只绘制三组指针、刻度弧线、刻度线与数字，不绘制表盘、标题及主界面设置。
- 增加 0–100% 指针/刻度对比阴影强度控制，与增益共同持久化；悬浮窗支持鼠标拖动定位。
- 新增悬浮仪表大小（120–400 px）与组间距（0–80 px）设置，调整时即时重排悬浮层并与其他参数一并保存。
- 按刻度弧线的可见直径计算悬浮仪表排布节距，使 0 px 间距时刻度实际相邻，而不是只压缩透明仪表控件之间的空隙；间距范围调整为 0–80 px。
- 将高不透明度白色粗描边替换为可调暖色柔光、窄轮廓与轻微暗色偏移，降低生硬感并保持深色背景上的辨识度。
- 将组件集成到整合版组件库，悬浮窗采用统一的设置窗 / 悬浮窗独立生命周期与托盘管理。
- 新增「显示标尺数字」开关，同步控制设置窗口和透明悬浮层刻度上的数字。
